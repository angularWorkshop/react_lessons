# Topic 25.1: RTL — Button & Form Tests

Lesson branch for the EduTec React course exercise.

## Goal

Write tests for Button and SignupForm components using React Testing Library and userEvent.

## Requirements

- test Button: render, click handler, disabled state
- test SignupForm: field rendering, validation errors, successful submit, success message
- use `getByRole` and `getByLabelText` — never `getByTestId`
- use `userEvent` for interactions — not `fireEvent`
- use `vi.fn()` for callback mocks

## Scripts

- `npm run dev`
- `npm run build`
- `npm run preview`
- `npm run typecheck`
- `npm run test`
- `npm run check`
