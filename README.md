# Topic 2.2: Dynamic JSX

Starter branch for the EduTec React exercise about expressions inside JSX.

## Task

Build a `ProfileCard` component with:

- avatar
- name
- role
- online or offline status
- a typed inline style object for the status color

## What to change

- move the profile data into variables
- keep hardcoded values out of the returned JSX
- type the status style object
- keep `className` and `htmlFor` correct

## Expected checks

- the profile card renders the expected content
- the status color depends on the computed state
- the JSX stays declarative and avoids inline hardcoded copy
- `npm run check` passes
