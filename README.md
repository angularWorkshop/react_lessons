# Capstone 3: Production-Ready Task Board SPA

Solution branch for the EduTec React course final capstone project.

## Goal

Build a production-ready Task Board SPA integrating Zustand, React Hook Form + Zod,
React Router with lazy routes, Error Boundaries, and React.memo optimization.

## Requirements

- Zustand stores with `persist` middleware for tasks and auth
- React Hook Form + Zod for validated task creation
- React Router with lazy-loaded routes and `RequireAuth` guard
- Error Boundary for crash resilience
- `React.memo` on TaskCard to prevent unnecessary re-renders
- Search/filter on the board
- Full TypeScript typing, no `any`

## Scripts
